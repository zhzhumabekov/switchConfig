Windows-серверы: AD, DHCP, DNS

По MAC-адресам с портов коммутаторов находятся имя компьютера и IP (из DHCP), описание, ОС и подразделение (из AD), имена статических адресов (из DNS). Всё только читается.

Источники

🔒 Пароли хранятся в data/switches.json в зашифрованном виде (Windows DPAPI): расшифровать их может только ваша учётная запись Windows на этом компьютере. В браузер пароли не передаются. Сервер доступен только с этого компьютера (127.0.0.1).
