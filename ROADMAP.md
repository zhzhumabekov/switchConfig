# План развития

Этапы упорядочены по пользе на единицу работы. Каждый этап даёт законченный результат.
Функция «кто из пользователей сидит за компьютером» в план не входит.

## Сделано

- Разбор конфигурации Huawei VRP: панель стека, профили портов, VLAN, L3, сервисы, замечания.
- Несколько коммутаторов, пароли зашифрованы (DPAPI), локальный сервер.
- Состояние портов (`display interface brief`), LLDP-соседи, таблица MAC, ARP.
- Поиск «где подключено устройство» по MAC, IP и имени.
- **Этап 1** (готов, 2026-09-30): имена устройств из DHCP, AD и DNS, поиск по имени компьютера, список неизвестных устройств.

## ~~Этап 1. Имена устройств на портах (DHCP + DNS + компьютеры AD)~~ — готово

- На каждом порту видно: `GE0/0/5 → PC-BUH-012 · 192.168.1.16 · Windows 11 · OU Бухгалтерия`.
- Поиск находит и по имени компьютера.
- Список «Неизвестные устройства»: MAC есть на порту, а в DHCP и AD его нет (чужие ноутбуки, личные роутеры, неучтённое оборудование).
- Источники: аренды и резервирования DHCP (MAC → IP, имя); обратный DNS для статических адресов; компьютеры в AD (описание, ОС, OU, последний вход).
- Нужно: RSAT или удалённое подключение к серверу; права на чтение DHCP (группа «DHCP Users»); чтение AD есть у любого пользователя домена.

## Этап 2. Автообновление и история изменений

- Сбор по расписанию: конфигурация, например, раз в сутки, состояние портов — раз в 15–30 минут.
- История версий конфига и страница «Что изменилось» с различиями между версиями.
- История подключений: какое устройство было на порту, куда переехало, когда появился неизвестный MAC.
- Отметки о событиях: коммутатор не отвечает, аплинк упал, появилась петля, изменился конфиг.

## Этап 3. Готовые команды для исправления

- К каждому замечанию добавляется блок команд, которые можно скопировать.
- Шаблоны «сделать порт рабочим местом / точкой доступа / принтером» по эталону.
- Команды только показываются, на коммутатор сами не отправляются.

## Этап 4. Эталонные настройки

- Описание эталона для каждого типа порта и обязательных глобальных настроек (NTP, syslog, SNMP, SSH).
- Сверка всех коммутаторов с эталоном и отчёт об отклонениях.

## Этап 5. Схема сети и состояние железа

- Схема соединений коммутаторов по LLDP.
- CPU, память, температура, блоки питания, вентиляторы, стек, время работы, версия прошивки.
- Уровни сигнала SFP-модулей (`display transceiver`).

## Этап 6. Отчёты и документация

- Экспорт таблицы портов в Excel: устройства, описания, VLAN.
- Паспорт коммутатора для печати.

## Этап 7 (по желанию). Изменение настроек из интерфейса

- Смена VLAN, включение и выключение порта, изменение описания.
- Предпросмотр команд, подтверждение, журнал изменений.
- Самый рискованный пункт, делается последним.
